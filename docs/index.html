Curiosity Compass

A personal desktop tool for producing and publishing original short videos.

What this is. Curiosity Compass is a command-line tool that runs on one person's own computer. It drafts a script, generates a voiceover and images, assembles them into a video, and uploads that video to a single YouTube channel owned by the same person. Every video is reviewed before it is published.

Who it is for

One person: its owner. There are no other users, no accounts, no sign-up, and no hosted service. It is not distributed or sold.

What it accesses

Only the owner's own Google account and YouTube channel, through OAuth 2.0, using these endpoints of the YouTube Data API v3:

  • videos.insert — uploading a video to the owner's channel
  • videos.list — checking upload and processing status
  • videos.update — correcting metadata after upload
  • thumbnails.set — setting a thumbnail
  • channels.list — confirming which channel is authorised

What it stores

A small local file listing the IDs and status of videos the owner uploaded, so a run can resume after an interruption. No data is sent anywhere except Google's own APIs, and nothing is shared with anyone.

Revoking access

Authorisation can be withdrawn at any time at Google's security permissions page, which immediately invalidates the stored credentials.

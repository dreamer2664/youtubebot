# Terms of Service

**Last updated:** 10 September 2026

## 1. What this is

Curiosity Compass is a personal desktop tool created and operated by a single individual,
Carlo Rella. It generates short original videos and uploads them to one YouTube channel
owned and operated by the same individual.

It is not a commercial product. It is not offered to the public, has no users other than
its owner, has no accounts, and charges nothing.

## 2. No user accounts

There is no sign-up, no registration, and no user-facing service. The only person who
uses this tool is its owner, running it on their own computer.

## 3. YouTube API Services

This tool accesses the YouTube Data API v3 under the
[YouTube API Services Terms of Service](https://www.youtube.com/t/terms) and the
[YouTube API Services Developer Policies](https://developers.google.com/youtube/terms/developer-policies).

The tool:

- uses only the endpoints it needs: `videos.insert`, `videos.list`, `videos.update`,
  `thumbnails.set` and `channels.list`
- uploads only original content created by the owner of this tool, to the owner's own
  channel
- does not access, aggregate, redistribute or store any third party's YouTube data
- does not modify or interfere with any functionality, data or content made available
  through YouTube API Services
- uses exactly one Google Cloud project, `my-uploader-508220`

Users can revoke access at any time at
<https://security.google.com/settings/security/permissions>, in accordance with the
Developer Policies.
